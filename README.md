# 환전 어디서? — 여행 환전 비교 계산기

국내 은행(하나은행) 환전 · 현지 환전소(원화/보유 외화) · 이중 환전 중 어디가 이득인지
실시간 환율로 비교하는 한국어 웹사이트. 기획은 [PRD.md](PRD.md) 참고.

## 실행

```bash
npm ci
npm run dev   # http://localhost:3000
```

## 입력과 비교

- `원화 / 이미 가진 달러 / 이미 가진 유로` 중 하나를 선택하고 그 통화로 금액을 입력합니다. 보유 외화의 비교 경로는 해당 외화를 선택한 경우에만 표시합니다.
- 금액 입력은 소수점과 쉼표를 포함한 원문을 유지합니다. 계산 가능한 현금 환전 방법이 2개 이상일 때만 순위와 추천을 표시합니다.
- 도시·국가 검색, 빠른 선택, 최근 도시 5개 저장, 통화 직접 선택을 지원합니다. 최근 도시는 같은 브라우저에만 저장됩니다.
- 통화쌍을 변경하면 해당 환전소 환율을 지웁니다. 같은 통화를 쓰는 도시로 이동하면 입력을 유지합니다.
- 이미 여행지 통화를 가진 경우에는 ‘환전 없이 사용’ 금액과 같은 원화 가치의 환전 방법을 구분해서 보여줍니다. 카드·ATM 참고 금액은 수수료를 반영하지 않으며 순위에 포함하지 않습니다.

## 검증

Node 24에서 다음 명령으로 실행합니다.

```bash
npm test                  # 계산·입력 상태·외부 데이터 검증
npm run typecheck
npm run build
npx playwright install chromium  # 최초 1회
npm run test:e2e           # 프로덕션 빌드로 실행, 포트 3100 사용
```

부하가 큰 환경에서 병렬 실행이 시간 초과되면 `npm run test:e2e -- --workers=1`로 순차 실행합니다. 테스트 제한 시간과 검증 항목은 동일합니다.

브라우저 테스트는 고정 환율 응답을 사용합니다. 소수점 순차 입력·실제 붙여넣기·커서 수정, 통화 전환, 검색·최근 도시, API 로딩·실패·일부 누락, 키보드·터치, 툴팁과 360/390/768/1280px 화면을 검증합니다. 데스크톱과 모바일에서 `비교 결과 보기` 버튼이 결과 제목으로 포커스를 옮기는지도 확인합니다. 캡처는 `test-results/`에 저장합니다.

## UI 구성

- 환전 조건 → 환율 입력 → 수령액 비교를 하나의 작업 영역에 배치합니다. 데스크톱은 두 열, 모바일은 입력 다음 결과 순서입니다.
- 입력하면 자동 계산하며, `비교 결과 보기`가 화면의 주된 실행 버튼입니다. 현금 환전 방법이 2개 이상일 때만 순위와 최대 수령 표시를 제공합니다.
- 초록색은 선택·최대 수령액·주요 버튼에 사용합니다. 일반 결과는 구분선으로 정리하고, 환율 정보와 여행 팁은 문서 흐름 안에 둡니다.
- `components/Icon.tsx`의 듀오톤 SVG 아이콘을 공유합니다. 장식용 배경 박스를 추가하지 않으며, 라벨이 있는 아이콘은 보조 기술에서 중복으로 읽지 않습니다.

## 코드 검사

```bash
npm run lint       # Oxlint + anti-slop, 소스를 수정하지 않고 검사
npm run typecheck  # 앱과 vendored 플러그인의 TypeScript 검사
```

Oxlint와 `@oxlint/plugins`를 **1.87.0**으로 함께 고정했습니다. 업그레이드할 때도 두 버전을 맞춥니다. `.oxlintrc.json`에서 anti-slop 일반 규칙 18개와 네이티브 `oxc/no-accumulating-spread`를 오류로 활성화합니다. Effect는 직접 의존성이 없어 추가 규칙을 활성화하지 않았습니다.

플러그인은 `tools/oxlint/anti-slop/`에 복사되어 이 레포에서 관리합니다. 원본 번들의 저장소·커밋은 확인되지 않았으며, 설치한 파일 38개의 해시와 Git 복원 방법을 [UPSTREAM.md](tools/oxlint/anti-slop/UPSTREAM.md)에 기록했습니다. 에이전트 도구·빌드/테스트 산출물·vendored 플러그인은 lint에서 제외합니다.

**2026-10-13 정리 완료:** 최초 오류 185건(간격 172건·타입과 이름 13건)을 수정했습니다. 규칙·오류 수준·검사 제외 범위를 유지했으며, 공백 정리와 의미 변경은 별도 커밋으로 기록했습니다. 현재 `npm run lint`는 오류 0건·경고 0건으로 통과합니다.

외부 데이터는 [Zod](https://zod.dev/api) 4.6.7로 입력 경계에서 검증합니다.

- `lib/rates.ts`: 공급자와 앱 API 응답을 검증합니다. 잘못된 환율 항목만 제외해 정상적인 부분 응답은 유지하고, 유효하지 않은 응답 형식은 기존 오류·폴백 처리로 넘깁니다. 수출입은행의 금액 문자열은 전체 형식을 확인한 뒤 숫자로 변환하며, 오류 응답과 휴일의 빈 배열을 구분합니다.
- `lib/recent-cities.ts`: 저장된 도시 목록에서 유효한 도시만 선택 순서대로 최대 5개 남기며 중복을 제거합니다. 잘못된 JSON이나 배열이 아닌 데이터는 빈 목록으로 처리합니다.
- 검사에서는 타입 단언·억제 주석으로 외부 데이터를 신뢰하지 않습니다. 검증을 통과한 값만 계산과 화면에 전달합니다.

파일·줄별 최신 진단은 `npm run lint -- --format unix`로 확인합니다. 간격 정리는 `npm run lint -- --fix`로 적용하고, 반복 실행 시 추가 변경이 없는지 확인합니다. 별도 포맷터는 설정되어 있지 않습니다.

`.env.local`에 한국수출입은행 API 키를 넣으면 국내 고시환율이 1순위로 적용됩니다
(없어도 Frankfurter/Open ER API 폴백으로 동작):

```
KOREAEXIM_API_KEY=발급받은키
```

## 계산 공식

- 하나은행 현찰 살 때 = `매매기준율 × (1 + 스프레드율 × (1 − 우대율))`
- 현금 환전 우대율: USD 90% / JPY·EUR 80% / HKD·SGD·AUD·CAD·NZD·CNY·THB·GBP·CHF 30%
- 카드·ATM 참고 금액 = 원화 환산 예산 ÷ 기준 환율 (100% 환율 우대 가정, 수수료 미반영)
- 보유 외화의 원화 가치는 현재 기준 환율로 환산하며, 과거 매입 가격에 따른 수익·손실을 의미하지 않음
